# Bibata Modern Classic

Cursors for the Cinnamon desktop preview, exported from
**[Bibata-Modern-Classic](https://github.com/ful1e5/Bibata_Cursor)** v2.0.7
(the theme used on the source Linux Mint machine).

- Source: Xcursor theme → 32×32 PNG with original hotspots  
- Applied via CSS custom properties `--cursor-*` in `styles.css`
